# P2 learning note

## What changed

The Streamlit app now shows every ranked memory candidate and its score. A user selects memories, reads the exact context, and approves that text before a local Ollama comparison. An edit or changed question invalidates the old selection. Narrow explicit preference conflicts are flagged, and simultaneously selecting both sides blocks generation. The app displays model output as text and never runs it.

## Data flow and key files

1. `src/memorygraph/store.py` stores local JSON memories.
2. `src/memorygraph/retrieval.py` ranks every candidate with the chosen method.
3. `src/memorygraph/conflicts.py` detects two documented explicit preference pairs.
4. `app.py` shows scores, captures the selection and approval, and calls `src/memorygraph/inference.py` for optional local comparison.
5. `tests/test_conflicts.py` checks conflict and selection behavior. Existing tests cover store and retrieval methods.

## Assumptions

- Python 3.12 and the pinned heavy dependencies were approved for this MVP.
- The fictional demo memories are examples, not user data.
- Local Ollama is optional and points to loopback.
- No model-generated code is executed.
- A user approval applies only to the currently selected context and question.
