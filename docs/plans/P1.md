# P1 plan: MemoryGraph reproducible MVP

## Scope and files

- Python 3.12 isolated environment (owner-approved exception to the supplied 3.11 default), pinned `requirements.txt`.
- `src/memorygraph/`: synthetic dataset generator, data schema, feature extraction and grouped evaluation, retrieval, graph memory, editable store, optional Ollama client.
- `experiments/config.py` and runnable scripts: fixed synthetic scenarios, random seed, split strategy, metrics, model versions, and artifact paths before results are generated.
- `data/`: generated synthetic CSV with provenance; `results/`: generated metrics and model artifacts.
- `app.py`: Streamlit demo for inspecting, adding, editing, deleting, and retrieving memories, with optional local inference.
- `tests/`: meaningful tests for generation, grouped split, retrieval, memory updates, and result schema.
- `docs/SAFETY.md`, `docs/REFERENCES.md`, `README.md`, and `docs/learning/P1.md`.

## Design

- Synthetic users each have distinct preferences, projects, and tools. Queries are generated from templates independent of training labels. Groups are synthetic user IDs to prevent the same persona leaking across train and validation.
- TF-IDF + logistic regression and random forest baselines use scikit-learn Pipelines and GroupKFold. Report precision, recall, F1, and retrieval precision@k/MRR. Results are synthetic demonstration results only.
- Semantic retrieval uses a pinned pretrained sentence-transformer model; compare on the same synthetic query-memory pairs. NetworkX stores memory-to-entity edges, with normalized entity aliases and a bounded graph-assisted score.
- Streamlit displays the selected memories and retrieved context before optional Ollama inference; inference is opt-in and no model output is executed.

## Safety and integrity

- Generated code is never executed. The demo handles plain text only.
- Synthetic labels and metrics are never described as real-user performance.
- No raw results are hand edited; scripts write JSON/CSV outputs.
- No energy claim until a documented measurement method is implemented.
- Local Ollama is optional; no API key or external service is required.

## Risks

- Downloading a pretrained embedding model may be slow or blocked. If blocked, keep the semantic adapter and mark it unverified.
- Synthetic task templates are limited and may let models learn surface patterns. Grouped validation reduces persona leakage but does not establish generalization to humans.
- The optional local inference backend may not be running; the demo must still work for retrieval.

## Open questions and assumptions

- The MVP uses fictional, synthetic coding preferences and does not use private conversation history.
- The owner approved Python 3.12 and heavy dependencies in this chat.
- No particular local LLM was specified, so Ollama is an optional backend; the model name is entered by the user in the demo.
